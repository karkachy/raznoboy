# Разнобой

Музыкальная афиша с поиском, подборками, профилем, пользовательскими оценками и демонстрационной покупкой билетов. Клиент написан на React и TypeScript, сервер — на Node.js и Express. SQLite хранит каталог концертов, аккаунты, сессии, голоса и оформленные билеты.

## Локальный запуск

Клиент и сервер — два отдельных приложения. У каждого своя папка, свой `package.json` и свой порт:

| Часть | Папка | Порт | Адрес |
|---|---|---|---|
| Сервер (API) | `Server/` | 5198 | http://localhost:5198/api |
| Клиент (сайт) | `client/` | 5173 | http://localhost:5173 |

Понадобятся Node.js 24 или новее и npm. Запуск в двух терминалах. В первом сервер:

```sh
cd Server
npm ci
npm start
```

Во втором клиент:

```sh
cd client
npm ci
npm run dev
```

Открой [сайт](http://localhost:5173/). Клиент сам отправляет запросы на `http://localhost:5198/api` (адрес задан в `client/src/api.ts`). Сервер разрешает их через CORS (`Server/middleware/cors.js`).

Посмотреть базу в терминале: `npm run db` в папке `Server` (список таблиц) и `npm run db -- Tickets` (строки таблицы). Скрипт открывает базу только для чтения.

Тесты запускаются в каждой папке отдельно: `npm test` в `Server/` и `npm test` в `client/`.

## Структура

| Путь | Назначение |
|---|---|
| `client/src/routes/` | Адреса страниц, дерево React Router и защита страниц профиля и покупки |
| `client/src/pages/` | Афиша, концерт, вход, регистрация, оформление и профиль |
| `client/src/components/` | Шапка, календарь, карточки, карусель, рейтинг и общий диалог на Radix UI |
| `client/src/api.ts`, `types.ts` | Адрес сервера, HTTP-запросы к API и типы данных |
| `client/src/auth/SessionContext.tsx` | Доступ к текущему пользователю, билетам и оценкам для компонентов |
| `client/public/` | Готовые обложки, шрифты, текстура и видео для шапки |
| `Server/index.js`, `Server/routes/` | Запуск Express и отдельные маршруты аккаунтов, концертов, билетов и оценок |
| `Server/middleware/session.js` | Чтение cookie и проверка входа для закрытых операций |
| `Server/middleware/cors.js` | Разрешение запросов от клиента с порта 5173 |
| `Server/middleware/logger.js` | Вывод каждого запроса к API с кодом ответа в терминал и запись в `Server/logs/requests.log`, включая ошибки 500 |
| `Server/db/` | Всё про базу данных: подключение, SQL-запросы, начальные данные (`seeds/`) |
| `Server/db/schema.sql` | Описание таблиц |
| `Server/db/show.js` | Просмотр таблиц в терминале (`npm run db`) |
| `Server/db/afisha.db` | **Сам файл базы SQLite.** Создаётся при первом запуске |
| `resources/` | Оригиналы обложек, скрипт подготовки AVIF и сведения об авторах |

## API

| Метод и адрес | Доступ | Действие |
|---|---|---|
| `GET /api/events` | все | Каталог концертов |
| `GET /api/session` | все | Текущий пользователь, его билеты и рейтинги |
| `POST /api/accounts`, `POST /api/login`, `POST /api/logout` | все | Регистрация, вход, выход |
| `PATCH /api/account` | вошедший | Изменить имя |
| `POST /api/tickets/:eventId` | вошедший | Оформить билет |
| `DELETE /api/tickets/:number` | владелец билета | Вернуть билет до даты концерта |
| `PUT /api/ratings/:eventId` | вошедший | Поставить или изменить оценку |
| `DELETE /api/ratings/:eventId` | вошедший | Удалить свою оценку |

При запуске `initializeDatabase()` заполняет каталог и десять исходных оценок на концерт. Собственные оценки и билеты сохраняются между запусками.
